# 主轴空转转速声音核对

检修员完成调速后，上传一段 **3～8 秒的空转声 WAV** 并填写铭牌允许的转速范围（300～6000 转/分），系统将录音等分三段做谱分析，自动找出三段共同支持的连续转速区间；仅当共同区间唯一且宽度不超过 30 转/分时确认转速，否则列出候选区间并提示无法确认。

## 输入约定

- WAV（PCM）：16 kHz、16-bit、单声道，时长 3～8 秒
- 铭牌转速下限/上限：300～6000 转/分之间的数值，且下限严格小于上限
- 输入有误（格式、时长、转速范围）时返回 400 并提示具体原因，不产生有效结果

## 判定规则

1. **三段等分**：录音按采样点等分为三段（长度差至多 1 个采样点）。
2. **谱峰拾取**：每段加 Hann 窗做 FFT，仅在 5～800 Hz 频带内取局部谱峰；峰值功率须达到该段频带最大功率的 1%，按功率降序最多保留 8 个最强峰。
3. **阶次支持**：只看 1～8 阶。若某转速 r（转/分）的 k 阶倍频 `k·r/60` 与某谱峰频率相差不超过 1 Hz，则该转速得到阶次 k 的支持。
4. **每段成立条件**：一个转速在每段都须有至少 3 个不同阶次支持，且这些阶次的最大公约数（gcd）为 1——排除仅由高阶谐波（如 2/4/6 阶）构成的伪转速。
5. **共同区间**：求三段支持转速集合的交集，输出全部连续区间，单点也算一个区间。
6. **确认/存疑**：
   - 共同区间恰有 **1 个** 且宽度 **≤ 30 转/分**：确认该区间，并列出区间中点在每段对应的支持阶次；
   - 其余情况（无共同区间、多个区间、唯一区间过宽）：列出全部候选区间并提示无法确认，需人工复核。
7. **结果只对应当前输入**：页面每次只展示最近一次录音与转速范围的结果；输入变更即清空旧结果。

> 关于区间宽度：±1 Hz 容差换算到转速后，区间半宽为 `60/k` 转/分，宽度由满足条件的最高阶 k 决定。含 1 阶时最宽约 40 转/分（超过 30，按规则存疑）；基频较弱、由 2/3/4 阶主导的机型区间宽度约 30 转/分，可被确认。

## 启动（Docker Compose）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

应用无状态、不落盘录音，无需数据卷。

## 本地开发（无 Docker 时）

```bash
python3 -m pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/check` | multipart 表单：`recording`（.wav）、`rpm_min`、`rpm_max`，返回核对结果 |
| `GET` | `/api/result/last` | 最近一次有效结果（无结果时 404） |
| `DELETE` | `/api/result/last` | 清除内存中的最近结果 |
| `GET` | `/api/health` | 健康检查 |
| `GET` | `/` | 核对网页 |

结果关键字段：

- `verdict`：`confirmed`（可确认）/ `unconfirmed`（无法确认）
- `confirmed_interval`：确认区间 `{lo, hi, mid, width}`（转/分），存疑时为 `null`
- `midpoint_orders[]`：确认区间中点在每段的支持阶次及谱峰匹配明细（理论频率、实测峰频、误差 Hz、相对功率）
- `candidate_intervals[]`：三段共同支持的全部候选区间（含单点标记 `is_point`）
- `segments[]`：每段拾取到的谱峰（频率、相对功率）与本段支持转速区间
- `warnings[]`：谱峰不足、某段无合格转速、无共同区间等提示

## 测试

```bash
python3 -m pytest tests/ -q
```

合成 WAV 生成器见 `scripts/gen_demo.py`（用 `-I` 隔离模式运行）：

```bash
python3 -I scripts/gen_demo.py /tmp/demo
# stable_1500.wav     1500rpm、2/3/4 阶主导 -> 可确认
# drift_rpm.wav       三段转速漂移 -> 无共同区间，无法确认
# even_harmonics.wav  仅偶数阶 -> 真实转速处 gcd=2，无法确认
```

## 目录结构

```
app/
  audio.py       WAV 校验（格式/时长）与三段等分
  matching.py    谱峰拾取、阶次支持、区间求交与确认判定
  service.py     转速范围校验与分析编排
  main.py        FastAPI 路由
  static/        单页前端（上传、结论、候选区间、各段谱峰展示）
tests/           音频解析、谱分析、输入校验、端到端 API 测试（42 项）
scripts/         演示 WAV 生成
```
